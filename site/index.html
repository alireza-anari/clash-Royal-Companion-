PLAYER INTELLIGENCE

شناخت بازیکن

برای تحلیل شخصی‌سازی‌شده به اطلاعات رسمی حساب نیاز داریم. در این مرحله می‌توان فایل JSON دریافت‌شده از API رسمی را مستقیماً داخل مرورگر باز کرد.

اتصال با Player Tag

API رسمی با Tag اطلاعات عمومی بازیکن را می‌دهد، اما خودش اثبات مالکیت حساب نیست.

دریافت خودکار فعلاً غیرفعال است. Backend پایتون باید از IP مجاز و دارای کنترل امنیتی به Supercell متصل شود. هیچ API Key را اینجا وارد نکن.

واردکردن امن JSON پروفایل

فایل پاسخ GET /v1/players/{tag} را انتخاب کن. داده در حافظه همین صفحه پردازش می‌شود و به سرور فرستاده نمی‌شود.

حداکثر ۲ مگابایت. فایل می‌تواند مشخصات کارت‌ها و دک فعلی را داشته باشد.

♙هنوز پروفایلی بارگذاری نشده است.

بدون داده واقعی، پروفایل ساختگی نمایش نمی‌دهیم.

BATTLE INTELLIGENCE

تاریخچه نبردها

نبردهای رویدادی با Trophy Road یکسان نیستند؛ نتایج را از هم جدا نمایش می‌دهیم و بدون Replay درباره جای‌گذاری کارت‌ها قضاوت نمی‌کنیم.

واردکردن Battle Log

فایل JSON پاسخ GET /v1/players/{tag}/battlelog را روی همین دستگاه انتخاب کن. داده‌ها در مرورگر پردازش می‌شوند و ارسال نمی‌شوند.

نبردهای دریافت‌شده
