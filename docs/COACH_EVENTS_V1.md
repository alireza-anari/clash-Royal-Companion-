Other official sources are mapped in coach-events-v1.mjs. Seven announcement entries include two Daily Puzzles series (second unknown dates), King of Cards, Quick Wit, Beatdown, Siege & Chip, and Royal Market. This is a partial calendar, not a live feed. No synthetic schedules in the active catalog.

Date-only announcements never imply exact UTC instants. Status uses a conservative day-boundary margin and labels the published window, not actual availability. Exact UTC support is tested using synthetic fixtures only; no exact challenge time invented. Unknown dates remain unknown. Past announcements are historical, not current. Sources are generated by the server, never selected by the model for deterministic event answers. Model-generated prizes, times and rules are discarded. Existing online inference and quota gate unchanged. No extra provider call.

Theme cards are only official weekly featured cards, not an allowed deck list. Compare IDs against current deck and bounded client-submitted candidates; missing subset does not mean unowned. No inferred arena, eligibility, active slots, balance or affordability. Preset puzzles never receive a personal deck recommendation. Actual complete event rules, rewards, entry fees, live start/end, full inventory and validated event decks remain release gates.

Acquisition guidance distinguishes historical announcements from general official support. Hero acquisition mechanics differ across older localized pages; avoid a numeric Hero Coin requirement until verified from the current English official source. No claim about player resource balance. Evolution Shards and Pass Royale guidance is general, not a guarantee of a specific reward.

Evaluation: event answers now use server-owned source attribution, not raw model source selection; the existing 60-case benchmark report predates this change and must not be treated as a new model score. Offline tests only. No deploy or production change.
