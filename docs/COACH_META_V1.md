## Data contract
Server-owned COACH_META_SNAPSHOTS in deploy/cloudflare/coach-meta-v1.mjs only. Reviewed aggregates from our own authorized Supercell API collection (reviewed:true is maintainer attestation, not cryptographic proof). Do not accept browser-supplied meta. Record version=1, source=supercell_api_own_aggregate, mode in ranked/trophy_road/grand_challenge/classic_challenge, cohort label, UTC window start/end/generated_at, total_deck_observations, rows of eight distinct card IDs, sanitized names, required_form (0 none/1 Evolution/2 Hero), min_display_level (observed/reviewed comparison requirement, not game eligibility), plays/wins/losses/draws. Denominator counts deck appearances rather than unique matches; count each participant deck once, deduplicate actual battles upstream, use consistent mode/cohort/window, exclude unknown outcomes, document sample coverage and patch boundary. Validate sample total >=200, row >=30, exact outcome sums, unique deck+form signature, <=50 rows, summed plays <= denominator, window <=14 days and generated within one day of end. Reject future-generated snapshots and data older than 48 hours. Thresholds are conservative engineering defaults, not statistical guarantees.

## Coach behavior
Explicit meta question (Ranked shortcut in menu) uses current online coach route and server deterministic answer rather than model-authored rankings. Only selected single mode's recent snapshot can render percentages. Output includes source, cohort, UTC window and sample counts; order by compatibility with submitted subset then observed usage, not predicted strength. Check card IDs, recorded display levels and required unlocks. Unknown/missing cards in submitted subset do not imply unowned. Active slots, Tower Troop and mode legality are not established. No counter or matchup claim without actual paired evidence; no recommendations based on balance notes alone. No snapshot means explicit unavailable answer. Existing model invocation and quota gates unchanged; no extra provider calls.
